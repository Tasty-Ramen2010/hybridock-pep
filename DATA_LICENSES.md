# Data licences and provenance

HybriDock-Pep's code is MIT-licensed ([LICENSE](LICENSE)). The **data** it uses is mostly not ours.
This file says where each dataset comes from, what part of it ships in git, and what we have and
have not verified. Where we have not verified something it says so, instead of guessing.
[docs/DATA_ARCHIVE.md](docs/DATA_ARCHIVE.md) covers where the large files live; third-party code and
weights are in [NOTICE.md](NOTICE.md).

Nothing here is legal advice. Last reviewed **2026-10-19**.

| Status | Meaning |
|---|---|
| **Checked** | Read from the source's own licence page, `LICENSE` file or Zenodo record on the date above |
| **Policy** | Stated in the source's published policy; not re-read for this file |
| **Open** | Terms not established — needs a decision before the data is relied on or redistributed |

## Open items

These two are shipped in git and their redistribution terms are not established.

1. **PDBbind-derived values.** `data/pdbbind_peptides.jsonl`, `data/hybridock_blind_925.csv`,
   `data/e331_matched_pdbids.json` and `data/e329_ref2015_pdbbind.json` carry per-complex
   experimental K<sub>d</sub>/K<sub>i</sub> (or ΔG), IDs, sequences and features for 925 complexes
   drawn from the PDBbind v2020 general set. The raw PDBbind structures are *not* shipped, and
   `docs/DATA_ARCHIVE.md` already notes that PDBbind prohibits third-party redistribution of its
   database. We have not established whether the affinity values themselves are covered. A resource
   that redistributed PDBbind-CN affinities reports removing them in January 2025 over licensing
   ([BioLiP2 download page](https://seq2fun.dcmb.med.umich.edu/BioLiP2/download.html)) — we have not
   verified that claim. **To resolve:** read the licence agreement on
   [pdbbind.org.cn](http://www.pdbbind.org.cn/) or ask the maintainers; if redistribution is not
   allowed, publish IDs and derived features only and rebuild the affinity column with
   `experiments/e108_ingest_pdbbind.py`.
2. **Wang *et al.* 2024 supplementary tables.** `SM_TableS1.xls` and `SM_TableS2.xls` (repository
   root) are the supplementary tables of Wang *et al.*, *Curr. Med. Chem.* **31**(26):4127–4137,
   doi:[10.2174/0929867331666230908102925](https://doi.org/10.2174/0929867331666230908102925),
   and `data/hybridock_wang2024_*.csv`, `data/test_complexes_wang.csv` derive from them. The files
   carry no licence statement. **To resolve:** check the publisher's supplementary-material terms or
   ask the authors; otherwise drop the `.xls` files and let `scripts/prep_wang_calibration.py` read
   a copy the user downloads.

## Used but not shipped

| Data | Where it is handled | Why not in git |
|---|---|---|
| PDBbind v2020 structures (~20 GB) | Register at [pdbbind.org.cn](http://www.pdbbind.org.cn/), then `experiments/e108_ingest_pdbbind.py` | Redistribution is prohibited |
| MISATO MD dataset (~124 GB) | Download from [misato-dataset.github.io](https://misato-dataset.github.io/) | Public and very large |
| PepPC formatted training data (~28 GB) | Rebuild from the raw archives with the scripts in `experiments/` | Licence terms not yet confirmed |
| Processed PDB fragment sets (~1.5 GB) | Regenerate | Source licence not yet confirmed |
| PDB structures for fine-tuning and benchmarks | `python scripts/download_from_manifests.py` | Public; fetched from `files.rcsb.org` |
| PPIKB, PEPBI | Download from the original sources (see [RESULTS.md](RESULTS.md)) | Large and external |

## Integrity

The data files that RESULTS.md reproduces from are checksummed in [ARTIFACTS.sha256](ARTIFACTS.sha256).
Run `python scripts/verify_artifacts.py` to confirm a checkout matches what the reported numbers
were produced from.

## Corrections

If you are a data owner and see something here that is wrong, or something of yours that should not
be in this repository, please open an issue (see [SECURITY.md](SECURITY.md) if it is sensitive).
